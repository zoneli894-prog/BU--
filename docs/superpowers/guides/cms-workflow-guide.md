# BU 网站后台管理 — 完整操作指南

> 本文档面向需要通过 CMS 后台编辑网站内容的团队成员。

---

## 一、前提条件

- 你已收到管理员发送的 Netlify 邀请邮件
- 你有一个可用的邮箱账号

---

## 二、首次登录流程

### 步骤 1：设置密码

1. 打开邀请邮件，点击其中的链接
2. 页面会跳转到 `https://curious-brigadeiros-4f1d1a.netlify.app/admin/`
3. 在弹出的窗口中输入你想要的密码（至少 6 位）
4. 点击 **"Set password"**

### 步骤 2：登录 CMS 后台

1. 访问 `https://curious-brigadeiros-4f1d1a.netlify.app/admin/`
2. 点击右上角 **"强制登录 / 设置密码"** 按钮
3. 在弹出的窗口中输入你的邮箱和密码
4. 点击 **"Log in"**

### 步骤 3：进入管理界面

登录成功后，你将看到 CMS 管理界面，左侧是内容集合列表：

- **时间轴 (Timeline)** — 编辑历史沿革节点
- **组织架构 (Org Chart)** — 编辑部门信息
- **首页内容 (Home)** — 编辑轮播幻灯片和最新动态
- **成员文章 (Articles)** — 发布和编辑成员文章
- **新闻动态 (News)** — 发布和编辑新闻
- **人物介绍 (Members)** — 编辑成员个人信息

---

## 三、编辑与发布流程

### 3.1 编辑已有内容

1. 在左侧列表中点击要编辑的集合（如"时间轴"）
2. 点击要编辑的条目
3. 修改字段内容
4. 点击右上角 **"Publish"** 按钮
5. 等待 1-2 分钟，Netlify 会自动重新构建网站
6. 访问 `https://zoneli894-prog.github.io/BU--/` 确认修改已生效

### 3.2 新建内容

1. 在左侧列表中点击要添加内容的集合
2. 点击 **"New [集合名]"** 按钮
3. 填写各字段
4. 点击 **"Publish"** 发布

### 3.3 删除内容

1. 打开要删除的条目
2. 点击右上角的 **"..."** 菜单
3. 选择 **"Delete"**
4. 确认删除
5. 点击 **"Publish"** 发布

---

## 四、各集合可编辑字段

| 集合 | 格式 | 可编辑字段 |
|---|---|---|
| 时间轴 | JSON | 年份、标题、描述 |
| 组织架构 | JSON | 部门名称、描述、结构关系 |
| 首页轮播 | JSON | 标签、标题、副标题 |
| 首页动态 | JSON | 标题、日期、标签、链接 |
| 成员文章 | Markdown | 标题、作者、分类、正文 |
| 新闻动态 | Markdown | 标题、日期、正文 |
| 人物介绍 | Markdown | 姓名、职位、头像、格言、正文 |

## 五、注意事项

### 5.1 构建时间

发布后网站不会立即更新，需要等待 Netlify 重新构建（约 1-2 分钟）。

### 5.2 两个网址的区别

| 网址 | 用途 |
|---|---|
| `https://curious-brigadeiros-4f1d1a.netlify.app/admin/` | CMS 后台登录和编辑 |
| `https://zoneli894-prog.github.io/BU--/` | 公开浏览网站 |

**不要**通过 Netlify 域名浏览网站，该域名仅用于 CMS 后台。

### 5.3 安全提醒

- CMS 后台无前端导航入口，仅知道 URL 的人可访问
- 编辑权限通过邀请制控制，只有被授权的邮箱可以登录
- 编辑操作会直接向 GitHub 仓库提交代码

### 5.4 常见问题

**Q: 忘记密码怎么办？**
A: 联系管理员，在 Netlify 后台重新发送邀请邮件，通过邮件链接重置密码。

**Q: 发布后网站没有更新？**
A: 等待 2-3 分钟。如果仍未更新，检查 Netlify Deploys 页面是否有构建失败。

**Q: 无法登录？**
A: 确认使用的是 Netlify 域名（`curious-brigadeiros-4f1d1a.netlify.app`），不是 GitHub Pages 域名。

## 六、管理员操作

### 添加新用户

1. 登录 Netlify 控制台
2. 进入站点 → **Site settings** → **Identity** → **Site members**
3. 点击 **"Invite a member"**
4. 输入对方邮箱 → 发送邀请

### 移除用户

1. 进入 **Site members** 列表
2. 找到要移除的用户
3. 点击 **"Remove"**
